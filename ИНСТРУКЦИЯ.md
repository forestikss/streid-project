# Гайд: Совместное кодирование

## ДЛЯ ТЕБЯ (первый раз уже сделано!)

✅ Ты уже все настроил! Теперь просто:

1. Открой папку `D:\nuclear` в IntelliJ IDEA
2. Запусти `2_start_sync.bat` (не закрывай это окно!)
3. Коди в IDEA - изменения автоматически отправляются другу

---

## ДЛЯ ДРУГА (первая настройка)

### Шаг 1: Установить Git
Если нет Git - скачать с https://git-scm.com/download/win

### Шаг 2: Установить Python
Если нет Python - скачать с https://www.python.org/downloads/

### Шаг 3: Склонировать проект
Открой командную строку (Win+R → cmd) и введи:

```bash
d:
cd D:\
git clone https://github.com/forestikss/streid-project.git
cd streid-project
```

### Шаг 4: Настроить Git пользователя
Запусти `setup_user.bat` - введи свое имя и email

### Шаг 5: Установить библиотеки
Запусти `1_install.bat`

### Шаг 6: Готово!
1. Открой папку `D:\streid-project` в IntelliJ IDEA
2. Запусти `2_start_sync.bat` (не закрывай это окно!)
3. Коди в IDEA - изменения автоматически синхронизируются!

---

## КАЖДЫЙ РАЗ КОГДА КОДИТЕ

1. Открываете проект в IntelliJ IDEA
2. Запускаете `2_start_sync.bat` (оба!)
3. Кодите - изменения синхронизируются каждые 3 секунды
4. Когда закончили - закрываете окно с батником

---

## ВАЖНО

- Оба должны держать `2_start_sync.bat` запущенным
- Не редактируйте один и тот же файл одновременно (будут конфликты)
- Если возникли конфликты - пиши мне, помогу разобраться

---

## СТРУКТУРА ПРОЕКТА

