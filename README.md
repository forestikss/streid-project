# Совместное кодирование

## Структура проекта

- `src/` - папка для вашего кода (кодите здесь!)
- `*.bat` - батники для настройки и запуска

## Как использовать

1. Запустите `2_start_sync.bat`
2. Открывайте файлы в папке `src/` в IntelliJ IDEA
3. Кодите! Изменения синхронизируются автоматически

## Для друга

```bash
git clone https://github.com/forestikss/streid-project.git
cd streid-project
# Запустить 1_install.bat
# Запустить 2_start_sync.bat
```

Теперь кодите в папке `src/` и все изменения будут синхронизироваться!
