# Настройка совместной работы через Git

## Шаг 1: Создайте репозиторий на GitHub
1. Зайдите на github.com
2. Создайте новый репозиторий (можно приватный)
3. Скопируйте URL репозитория

## Шаг 2: Настройте локально (ОБА делают это)

```bash
# Клонируйте репозиторий
git clone https://github.com/ваш-username/ваш-repo.git
cd ваш-repo

# Установите зависимости
pip install -r requirements.txt

# Запустите автосинхронизацию
python auto_sync.py
```

## Шаг 3: Кодите!
- Открывайте файлы в IntelliJ IDEA
- Скрипт автоматически синхронизирует изменения каждые 3 секунды
- Изменения друга появятся автоматически

## Преимущества:
✓ Работает через интернет (через GitHub)
✓ Бесплатно
✓ Не нужен сервер
✓ История изменений сохраняется
✓ Работает с любым редактором
